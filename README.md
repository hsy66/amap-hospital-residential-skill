# amap-hospital-residential-skill

> 密钥只放 .env 或环境变量，不要提交。

给定医院名称或地址，查询直线 0.8–5 公里内的住宅小区。每要一个小区才调用一次周边搜索，凑够就停。

## 运行

```bash
export AMAP_KEY=你的高德Web服务key   # 或在脚本同目录放 .env（已 gitignore）
python amap_nearby_residential.py "武汉协和医院" "武汉协和医院" "湖北省人民医院" --city 武汉 -n 1
```

每个参数是名单里的一行，重复的医院会接着给不同的小区。`-n` 是这一行要几个，默认 1。`--format md|json|csv`，`--seed` 可复现。stderr 分开打印地理编码次数和周边搜索次数。

## 怎么省配额

- 医院定位用地理编码，走基础 LBS 配额（个人认证约 15 万次/月），不占搜索配额。
- 周边搜索走基础搜索配额（个人认证 5000 次/月，关键字、周边、多边形、ID 查询合用）。返回 25 条也只算 1 次。
- 8 个方向、两圈距离轮流取点，半径 800 米，只要第 1 页里的 1 个小区。空地点最多把尝试次数加到需要个数的 2 倍。
- 不从医院中心翻页：官方限制同一组参数最多 200 条，而且按离圆心的距离排序，外圈轮不到。

## 过滤

类型只留住宅区 `120302` 和别墅 `120301`。去掉宿舍、公寓、写字楼、商铺、停车场、还建房和道路名。`东区/西区`、`1号/2号`、`一期/二期` 收成同一个小区；`阳光100` 不会因此和 `阳光城` 算成同一个。
